# tap.dc-bakery.kz

Taplink (Instagram bio link) для **DC Bakery by del Cappuccino** — B2B-поставки
десертов, выпечки, полуфабрикатов и мяса (халал) для кофеен, ресторанов, отелей
и магазинов в Казахстане.

Статичный одностраничник. Ведёт на основной сайт `dc-bakery.kz`, WhatsApp и
Instagram; показывает контакты и краткую информацию о компании.

- `index.html` — страница (встроенный CSS, шрифт Montserrat)
- `assets/` — логотип, иконка (фавикон), фото продукции
- `CNAME` — кастомный домен для GitHub Pages

Деплой: GitHub Pages из ветки `master` (корень). Домен `tap.dc-bakery.kz`
через CNAME-запись → `<owner>.github.io`.
